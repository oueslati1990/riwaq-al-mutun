# Spec 000 — Vision & MVP
# المواصفة 000 — الرؤية ونطاق MVP

**الحالة / Status:** ✅ Approved  
**المرحلة / Stage:** Closed — decisions recorded below

---

## المشكلة / Problem

طالب العلم الذي يريد حفظ المتون العلمية (كمتون الحديث والفقه والنحو) لا يجد أداة رقمية تناسبه:
- تطبيقات الحفظ العامة (Anki, Quizlet) لا تدعم العربية والتشكيل بصورة كافية
- استيراد المتون من PDF أو صورة يتطلب جهداً يدوياً كبيراً
- لا توجد أداة تجمع: استيراد → تصحيح → حفظ → مراجعة متباعدة في تجربة واحدة عربية RTL

---

## المستخدم المستهدف / Target User

طالب علم شرعي يقرأ ويكتب العربية بطلاقة، يستخدم Windows، يريد:
- استيراد متن من صورة أو PDF بأقل جهد
- حفظ المتن بيت بيت مع تسميع ذاتي
- مراجعة ما حفظه دورياً دون الحاجة لإدارة جدول يدوي

**ليس المستهدف حالياً:** طلاب المدارس، تعليم اللغة العربية كلغة أجنبية، المتون غير العربية.

---

## القيمة المقدمة / Value Proposition

تطبيق Windows يجمع استيراد المتون العربية + مراجعة النص + نظام حفظ بمراجعة متباعدة، في تجربة عربية RTL أصيلة، بيانات محلية بالكامل.

---

## نطاق MVP / MVP Scope

### داخل MVP ✅

1. إنشاء متن يدوياً وإضافة أبواب وأبيات مشكولة
2. استيراد صورة أو PDF واستخراج مسودة نص عربي (OCR)
3. مراجعة المسودة وتصحيحها واعتمادها دون فقدان الأصل
4. تقسيم المتن إلى وحدات حفظ (أبيات)
5. تنفيذ جلسة حفظ وتسجيل تقييم ذاتي
6. رؤية مراجعات مستحقة وفق سياسة موثقة (قريبة وبعيدة)
7. البيانات تبقى عبر إعادة التشغيل
8. نسخة احتياطية واستعادة ناجحة
9. واجهة بالعربية وRTL سليمة

### خارج MVP ❌

- مزامنة سحابية أو بين أجهزة
- دعم الصوت أو التحقق الصوتي من التسميع
- تعدد المستخدمين
- ترجمة المتون أو الشرح
- إشعارات خارج التطبيق
- تطبيق iOS/Android
- مشاركة المتون بين المستخدمين
- إحصاءات متقدمة (مرحلة 7)

## معايير القبول / Acceptance Criteria

| # | المعيار | قابل للاختبار؟ |
|---|---|---|
| AC-01 | المستخدم ينشئ متناً يدوياً بأبواب وأبيات مشكولة ويحفظها | ✅ |
| AC-02 | المستخدم يستورد صورة PNG/JPEG أو PDF ويرى نص OCR مسودة | ✅ |
| AC-03 | يمكن تصحيح النص المستخرج واعتماده، والملف الأصلي لا يُحذف | ✅ |
| AC-04 | المتن يُقسَّم إلى وحدات حفظ (بيت أو مجموعة أبيات) | ✅ |
| AC-05 | جلسة حفظ تعرض بيتاً، يخفيه المستخدم ويسمّع، ثم يقيّم نفسه | ✅ |
| AC-06 | التطبيق يعرض «مراجعات اليوم» المستحقة بعد إغلاق التطبيق وإعادة فتحه | ✅ |
| AC-07 | النسخ الاحتياطي يُنشأ ويُستعاد بنجاح مع بقاء جميع المتون | ✅ |
| AC-08 | جميع النصوص تظهر RTL بدون كسر مرئي في عرض 1366×768 | ✅ |
| AC-09 | التطبيق يبدأ ويعمل بدون اتصال بالإنترنت | ✅ |

## القرارات المعتمدة / Decisions

| # | القرار |
|---|---|
| Q-01 | **OCR: Tesseract محلي** — لا ترسَل ملفات المستخدم لأي خدمة خارجية. مزود OCR خلف `IArabicOcrProvider` قابل للاستبدال لاحقاً. |
| Q-02 | **مقياس التقييم: 3 درجات** — `0 = لم أتذكر` / `3 = تذكرت بصعوبة` / `5 = تذكرت بسهولة` (يتوافق مع جودة SM-2) |
| Q-03 | **الخوارزمية: SM-2 مبسطة** — EF ابتدائي = 2.5، الحد الأدنى = 1.3، فواصل البداية: 1 يوم، 6 أيام، ثم `الفاصل السابق × EF`. |
| Q-04 | **PDF متعدد الصفحات** — جميع الصفحات تُعالَج في MVP، صفحة بصفحة لتجنب استهلاك الذاكرة. |
